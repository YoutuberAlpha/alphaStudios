Important

Alpha files begin with name<(filename)>, followed by <aph> ... <aph>. Chain commands with a dot outside arguments, e.g. rpt<(2)>.txpp<("Hi")>. Alpha commands use <()> or multiline <( ... )>, not plain (). Comments use &&comment&& in Alpha; variables use !name! in bright green; // comments work only inside <js> blocks. Ctrl+Enter runs supported, safe Alpha output commands in the Run Console. System-access commands are not executed. Rules not yet defined in your language file are flagged cautiously.
